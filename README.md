# WannaEat 乐队主页

WannaEat 是一个轻量、响应式的乐队介绍主页，用于展示乐队形象、音乐风格和现场信息。项目使用原生 HTML 与 CSS 构建，无需安装依赖或配置构建工具。

## 页面内容

- WannaEat 乐队主视觉与品牌标志
- 乐队简介与品牌文案
- POP、ROCK、LIFE 三种音乐风格介绍
- 现场演出信息与联系入口
- 移动端适配、平滑滚动和交互悬停效果
- 使用 `icon.png` 作为页面主视觉和浏览器标签图标

## 项目结构

```text
.
├── index.html   # 页面结构与内容
├── style.css    # 页面样式与响应式规则
├── icon.png     # WannaEat 乐队标志
└── README.md    # 项目说明
```

## 本地预览

直接用浏览器打开 `index.html` 即可预览。也可以启动一个本地静态服务器：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 技术栈

- HTML5
- CSS3
- 原生响应式布局

项目当前为静态页面，后续可继续接入真实的音乐平台链接、成员信息、演出日历和社交媒体入口。
